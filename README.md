# EDF Viewer

Streamlit 腦波檢視器。用 MNE 讀 EDF、Plotly 畫互動波形。

```bash
streamlit run /Users/appletina/edf_viewer/app.py
```

## 檔案怎麼進來

- **`data/` 目錄** — 把 `.edf` 丟進 `edf_viewer/data/`，側欄下拉就會出現
- **上傳** — 側欄切到「上傳檔案」

## 睡眠分期：兩條軌道並排

**技師判讀**（自動載入，不用按任何按鈕）

| 來源 | 條件 |
|---|---|
| RemLogic Event Export | EDF 旁邊的**同名 `.txt`**（`GT028-170725H-28.EDF` ↔ `GT028-170725H-28.txt`）。逐 30 秒的分期 ＋ arousal ＋ Lights On/Off |
| Sleep-EDF | 同前綴的 `*-Hypnogram.edf`，走 `mne.read_annotations()` |

`data/` 裡放的是 symlink，判讀檔留在 Google Drive 原資料夾，所以會先解到真實路徑再找。
溫度實驗 129 個第二階段 EDF 裡有 **115 個**找得到 RemLogic 判讀檔。

**自動判讀**（按側欄「執行自動判期（YASA）」，結果存到 `~/.edf_viewer_cache/`，下次直接載入）

EEG／EOG／EMG 各自用**原生取樣率**讀出來、重取樣到 100 Hz 再送進 YASA，
不經過「先升頻到 500 Hz 再降回 100 Hz」那一手。一份 8.5 小時的全夜檔約 4 秒。

**畫面上**

- 導覽列下方：`技師 N2` ／ `自動 N2 87%` ／ `✓` 或 `✗`，純文字加分期色
- Hypnogram：技師實線、自動虛線疊在同一張圖，arousal 在下緣打紅色刻度，綠線是目前位置
- 導覽列多一顆 `≠`：**跳到下一個兩邊判讀不一致的 epoch**
- 底部 expander：一致率、Cohen κ、混淆矩陣、各期逐期一致率
- 側欄可切「分期跳轉依據」＝技師或自動

實測一致率（5 個全夜檔）：

| 檔案 | 一致率 | Cohen κ | 各期 |
|---|---|---|---|
| NW_GT029 24°C | 85.1% | 0.777 | W 96 / N1 38 / N2 85 / N3 94 / REM 86% |
| OW_GT035 20°C | 84.7% | 0.795 | W 95 / N1 35 / N2 87 / N3 97 / REM 89% |
| NW_GT028 28°C | 80.5% | 0.736 | W 84 / N1 41 / N2 86 / N3 94 / REM 84% |
| NW_GT027 22°C | 75.0% | 0.650 | W 96 / N1 36 / N2 72 / N3 100 / REM 83% |
| OW_GT036 26°C | 59.8% | 0.470 | W 92 / N1 20 / N2 59 / N3 74 / REM 54% |

N1 每一份都最差（20–41%），這是常態——人類判讀者之間在 N1 的一致度本來就最低。
**自動判期是拿來定位和篩檢用的，不能取代技師判讀。**
一致率特別低的檔（GT036）值得回頭看訊號品質，而不是當成 YASA 壞掉。

## 介面

- 頂部一行 caption：檔名、頻道數、取樣率、總時長、錄製時間
- 導覽列（波形圖正上方，同一行）：`−100 −1 +1 +100`、epoch 編號輸入框、五個分期跳轉鈕
- 波形圖：Plotly，可滾輪縮放、拖曳平移，每頻道一個子圖、共用 X 軸
- 波形圖下方 expander：各頻道的最大／最小／平均／標準差（預設收合）
- 側欄：epoch 長度、頻道選擇、Y 軸穩健縮放、每頻道高度

只讀目前 epoch 那一段資料，所以全夜檔開起來跟短檔一樣快。

## 附帶：K&Y `.RAW` 直讀

`readers.py` 另外實作了 K&Y-SS001（KY1_12 記錄器）原始檔的讀取，
`data/` 裡放 `.raw` 一樣開得起來，**不必先用原廠程式轉 EDF**。

格式是逆向工程出來的，已拿同一筆記錄的原廠 `convert (EDF)` 輸出逐點比對驗證：
兩種取樣率組態、全部 8 個通道、多個時間點，差值都是 0。

```
0x000  b'K&Y-SS001\x1a'      magic
0x00e  'KY1_12'              機型
0x022  uint16                版本
0x024  uint16                通道數 nch
0x026  17 × pascal string    取樣率；[0] = 多工基頻，[1..nch] = 各通道
...    uint16 type、nch bytes gain code
0x200  資料：little-endian uint16，值 = digital(0..4095) << 4
```

資料以基頻（500 Hz）為節拍多工：第 *i* 個 frame 依通道宣告順序，輸出所有滿足
`i % (基頻 / 該通道取樣率) == 0` 的通道各一個樣本。

已知的兩種組態（都是 8 通道 EMG/EOG/EEG/ECG/Temp/X/Y/Z）：

| 組態 | EMG | EOG | EEG | ECG | Temp, X, Y, Z |
|---|---|---|---|---|---|
| A（158 檔） | 500 | 250 | 125 | 125 | 62.5 Hz |
| B（40 檔） | 250 | 125 | 125 | 500 | 62.5 Hz |

RAW header 沒有時間戳，起始時間依序取自：同名 `.EDF` → 同名 `.TXT` 的 `t hh:mm:ss` → 檔案修改時間。

`readers.py` 裡的 `EDFFile` 也是寬容版 EDF 解析器，可以打開 header 不合規、
`pyedflib` 直接拒開的那批 KY1_12 轉出檔（app 預設走 MNE，MNE 同樣讀得動）。
